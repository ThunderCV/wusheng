# 无声证词

线下多人推理游戏。法医知道真相但不能说话，只能在勘查板上做标记；侦探们从所有人面前的牌里推理出凶手、凶器和线索。凶手混在侦探中间一起讨论。每人的手机用来看身份、看牌、看勘查板和指认。

- 4 到 10 人，每人一台手机；房主可以指定谁当法医，也可以随机
- 身份按住才显示，松手盖上；真相只发给法医、凶手、帮凶的手机（服务器端控制）
- 指认内容保密，失败只公布是谁失败了；凶手和帮凶也能用徽章装样子（一定算失败）
- 有单人试玩模式（自动加测试玩家，可切换视角，可一键让测试玩家完成当前步骤）

## 规则摘要

| 身份 | 人数 | 知道什么 |
|---|---|---|
| 法医 | 1 | 凶手、帮凶、真相。全程不许说话 |
| 凶手 | 1 | 自己选的真相、帮凶是谁 |
| 帮凶 | 0–1（6 人以上可开启） | 凶手是谁、真相 |
| 侦探 | 其余 | 什么都不知道 |

1. 除法医外每人面前有 4 张凶器、4 张线索，所有人可见。凶手从自己的牌里选 1 件凶器 + 1 条线索作为真相
2. 第 1 轮：法医标记「死因」，再从 5 块随机勘查板里挑 3 块各标一个选项
3. 大家按手机上的发言顺序讨论，结束后由法医进入下一轮
4. 第 2、3 轮：法医拿到 2 块新板，标记其中 1 块，同时撤下 1 块旧板（死因板不能撤）
5. 每人 1 枚徽章，讨论阶段随时可以指认「某人 + 他的 1 件凶器 + 1 条线索」，三样全对侦探方赢
6. 第 3 轮讨论结束后进入「最后指认」：还有徽章的人逐个选择指认或放弃，全部决定完才结算
7. 没人说中，或者所有侦探徽章都用完了，凶手方赢

手机端还有几个辅助：法医可以点一下显示或收起真相（显示时会高亮凶手的牌）；侦探点桌面上的牌可以划掉，帮自己排除嫌疑，只有自己看得到。

## 改内容

- 文字、人数、轮数、手牌数、帮凶门槛：`config.js`
- 凶器、线索、勘查板：`cards.js`（随便加减，启动时会检查数量够不够）

## 运行

只需要 Node.js 18 以上，没有任何依赖。

```bash
node server.js          # 默认端口 3000，可用 PORT=8080 node server.js 修改
npm test                # 用测试玩家自动跑 2100 多局，检查规则和信息隔离
```

启动后终端会打印本机地址和同一 Wi-Fi 下手机访问的地址。

## 部署

和「城墙之誓」一样：常驻 Node 进程、状态存在内存里，部署到 Render / Railway / Fly.io 等，只开 1 个实例（已附 `render.yaml`）。启动命令 `node server.js`，端口读 `PORT`，健康检查 `GET /healthz`。服务重启后进行中的房间会丢失。
